# 🎆 New Year Interactive Experience

An interactive New Year themed web project designed to reflect on the past year with positivity and welcome the new year with hope.  
Built with smooth animations, video elements, and a clean modern UI.

---

## ✨ Features

- 🎥 New Year recap video integration  
- 🎬 Smooth animations using **GSAP**
- 🖱️ Scroll-based interactions
- 📱 Responsive design (desktop & mobile)
- 🌙 Clean and minimal UI for better focus

---

## 🛠️ Tech Stack

- **HTML5** – Structure  
- **CSS3** – Styling & layout  
- **JavaScript (ES6)** – Interactivity  
- **GSAP** – Animations
